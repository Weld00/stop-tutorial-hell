# Contributing to Stop Tutorial Hell

Useful changes make this resource easier to use without requiring the accompanying product.

For an artifact recipe, include the focus, prerequisites and permitted inputs, the smallest inspectable result, a check that could fail, the limits of the evidence, and a conditional Day-30 review. An example is not a mandatory project or a promise of competence in seven days. Do not require publishing a demo, buying a service, or showing a fixed number of failures.

- Fix unclear instructions, broken links, or accessibility problems.
- Propose a small change and explain which decision or review it improves.
- Label fictional examples as fictional. Share only information you have permission to publish.
- For research-based claims, link to the original source and explain its limits. Do not present a planning suggestion as a validated scientific rule.
- Keep different constraints and legitimate non-career interests in mind. Avoid universal weekly-hour requirements or automatic career verdicts.
- Do not add affiliate links, link exchanges, unrelated product lists, copied course material, or promotional issues.
- Do not post personal assessment answers, credentials, confidential work, or real client data.

By submitting a contribution, you agree that your contribution is provided under this resource's MIT license. Contributions should be your own work or clearly identify compatible permissions.

No code setup is required: changes are ordinary Markdown files. Maintainers may ask for a narrower example or clearer evidence before accepting a change.
